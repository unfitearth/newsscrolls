NewsScrolls

Try it live → https://indiannewsautoscroller.vercel.app/

A calm way to keep up with Indian news. NewsScrolls shows one headline at a time in big, bold type and moves to the next on its own. Tap a headline to read the full story.

Built for a second monitor, a TV, or a phone propped on your desk. No feed, no thumbnails, no infinite scroll.

What it does

Pulls the latest headlines from Google News India RSS Feed (you can use any news api as well, rss was free)
Auto-advances every 5, 10, 15, 30 or 60 seconds
Pause, skip back, skip forward
Falls back to proxy fetchers if the feed is blocked, so it keeps working in the browser with no backend

Stack: Next.js 15, React 19, TypeScript, Tailwind 4. Deployed on Vercel.
